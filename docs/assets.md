# 3D Asset Attribution

X-FACTORY에 포함하는 외부 3D 모델, 텍스처, 폰트와 기타 시각 에셋의 출처 및 라이선스를 기록한다.

## Asset Strategy

- 밝은 야외 공장 지형, 도로, 기본 건물과 설비는 Three.js geometry를 우선 사용한다.
- Player와 IX를 포함한 외부 GLB/GLTF는 라이선스와 효과가 명확할 때만 추가한다.
- 특정 게임, 캐릭터, UI 또는 상용 IP를 복제하지 않는다.
- 출처와 라이선스를 확인할 수 없는 에셋은 최종 제출본에 포함하지 않는다.
- 에셋 품질보다 low-poly, 작은 texture, 적은 material과 빠른 로딩을 우선한다.

## Current Usage

현재 밝은 야외 공장 기반 지형, 자연물, Player, 여섯 Zone의 건물·설비·공원 오브젝트는 Three.js 기본 geometry와 프로젝트 내부 material만 사용한다. 외부 모델, 텍스처, 이미지 또는 폰트는 아직 사용하지 않았다.

따라서 현재 별도로 표시할 외부 에셋 라이선스는 없다.
